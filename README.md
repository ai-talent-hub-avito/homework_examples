**Homework Examples**

Репозиторий содержит примеры домашних заданий из образовательных программ Авито, которые используются **для разработки и тестирования AI-помощника для предварительного ревью домашних работ.**

Материалы позволяют проверить, насколько AI-помощник способен:
- понимать условие задания;
- анализировать выполненную работу;
- выявлять ошибки и недочёты;
- отличать слабое решение от хорошего и топового;
- формировать содержательное предварительное ревью;
- работать с заданиями разных типов и образовательных направлений.

**Критерии оценивания решений**
Для каждой домашней работы предусмотрены собственные критерии оценивания, которые указаны в соответствующем файле с условием задачи.
Категории решений в репозитории соответствуют полученным баллам по этим критериям:
- топ — решение получило высокий балл и соответствует уровню лучших выполненных работ;
- норм — решение получило средний балл и в целом соответствует требованиям, но имеет определённые недочёты;
- плохо — решение получило низкий балл и содержит существенные ошибки или нарушения требований.

Таким образом, обозначения топ, норм и плохо отражают оценку работы на **основе критериев конкретного задания, а не являются субъективной классификацией внутри данного репозитория**.
При анализе домашних работ **AI-помощнику необходимо учитывать критерии оценивания**, указанные в условиях соответствующего задания.
