**Homework Examples**

Репозиторий содержит примеры домашних заданий из образовательных программ Авито, которые используются **для разработки и тестирования AI-помощника для предварительного ревью домашних работ.**

Материалы позволяют проверить, насколько AI-помощник способен:
- понимать условие задания;
- анализировать выполненную работу;
- выявлять ошибки и недочёты;
- отличать слабое решение от хорошего и топового;
- формировать содержательное предварительное ревью;
- работать с заданиями разных типов и образовательных направлений.


**Структура репозитория**

Go
- task 1
- task 2 
- task 3

Важно: для Task 1, Task 2 и Task 3 используется одна общая домашняя работа, которая выполняется последовательно и дополняется на каждом этапе. Поэтому решения не разделены по отдельным папкам task 1, task 2 и task 3.

В папках норм, плохо и топ находятся полные домашние работы, распределённые по субъективной оценке качества выполнения:

плохо — работы с существенными недостатками;

норм — хорошие, но не идеальные работы;

топ — наиболее качественные работы.

Таким образом, одна и та же работа может охватывать требования всех трёх заданий.
